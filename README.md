## Objetivo

Desarrollar programas utilizando clases, objetos y métodos, lo cual permite disminuir errores y reutilizar el código.

## Ejercicios

| # | Archivo | Tema | Concepto |
|---|---------|------|----------|
| 1 | `Ejercicio1.java` | Libro y Autor | Objeto como atributo |
| 2 | `Ejercicio2.java` | Rectángulo | Firmas de métodos |
| 3 | `Ejercicio3.java` | Producto y Venta | Objeto como parámetro |
| 4 | `Ejercicio4.java` | Transferencias | Objeto como parámetro |
| 5 | `Ejercicio5.java` | Biblioteca | Colaboración entre clases |
| - | `TodosLosEjercicios.java` | Los 5 ejercicios juntos | Integración |

## Cómo ejecutar

```bash
# Un ejercicio individual
javac Ejercicio1.java
java Ejercicio1

# Todos los ejercicios juntos
javac TodosLosEjercicios.java
java TodosLosEjercicios
```

## Conclusiones

- La programación orientada a objetos permite disminuir errores en el código y reutilizarlo.
- Pasar objetos como atributos o parámetros permite que las clases colaboren entre sí.
- Usar el tipo de retorno correcto en cada método hace el código más claro y fácil de mantener.

## Recomendaciones

- Revisar el material y la bibliografía antes de realizar las tareas.
- Acudir a las tutorías académicas si hay dudas sobre el tema.
- Comentar el código.
